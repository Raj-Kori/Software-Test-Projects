# YouTube Web Application — Manual Test Scenarios

## 📌 Project Overview
**Application Under Test (AUT):** [YouTube](https://www.youtube.com/)

**YouTube** is a video-sharing platform that allows users to search, stream, rate, share, save videos, and interact with content via comments and playlists.

This project focuses on **Test Scenario Identification** and **High-Level Coverage Mapping** across core workflows, ensuring critical business paths and edge cases are identified before detailed test case execution.

---

## 🎯 Scope of Test Scenarios
The scenarios created in this module cover the following functional areas:
* **Search & Filter Operations:** Live keyword search, multi-parameter filtering (Upload Date, Duration, Type), and sorting algorithms.
* **Video Playback & Controls:** Video rendering, seeking, volume control, quality switching, and player state transitions.
* **User Engagement:** Likes/dislikes, channel subscriptions, commenting interactions, and playlist generation.
* **UI & Navigation:** Responsive grid layouts, side menu toggles, and light/dark theme modes.

---

## 🛠️ Design Approach
* **Brainstorming & Coverage Mapping:** Identifying critical user journeys and potential edge-case scenarios.
* **Test Techniques Used:** Equivalence Partitioning (EP), Boundary Value Analysis (BVA), and State Transition for player state logic.
